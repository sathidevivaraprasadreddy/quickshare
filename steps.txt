1. ARCHITECTURE & ZERO-COST (₹0) STACK OVERVIEW
================================================================================
QuickShare is an ephemeral, secure file-sharing web service inspired by the core 
functionality of Send Anywhere:
- Select single or multiple files with drag-and-drop.
- Real-time animated upload progress bar (0% - 100%).
- Unpredictable 128-bit cryptographic tokens (crypto.randomBytes).
- Recipient download page for single files or zipped bundle (.zip).
- Owner Revocation Key to delete files and kill the link at any time.
- Configurable expiration (1h, 6h, 24h, 3d, 7d) with automatic background shredder.
- QR Code display for instant mobile camera scanning.

Verified ₹0 Free Hosting Providers:
1. Frontend Hosting: Vercel (100 GB/mo edge bandwidth, free *.vercel.app domain).
2. Backend Hosting : Render (512 MB RAM, free *.onrender.com domain, TLS cert).
3. Cloud Database  : TiDB Serverless (5 GB row storage forever free, 100% MySQL).
4. Cloud Storage   : Supabase Storage (1 GB persistent S3 storage, zero card).
5. Code Repository : GitHub (Free private/public Git hosting).

1. Create SQL Schema File:
   File: backend/database/schema.sql
   -----------------------------------------------------------------------------
   CREATE DATABASE IF NOT EXISTS quickshare_db
     CHARACTER SET utf8mb4
     COLLATE utf8mb4_unicode_ci;

   USE quickshare_db;

   CREATE TABLE IF NOT EXISTS share_sessions (
     id INT AUTO_INCREMENT PRIMARY KEY,
     share_token VARCHAR(64) NOT NULL UNIQUE,
     revoke_token VARCHAR(64) NOT NULL,
     total_size_bytes BIGINT NOT NULL DEFAULT 0,
     file_count INT NOT NULL DEFAULT 1,
     expires_at DATETIME NOT NULL,
     created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
     is_revoked TINYINT(1) NOT NULL DEFAULT 0,
     download_count INT NOT NULL DEFAULT 0,
     INDEX idx_share_token (share_token),
     INDEX idx_expires_at (expires_at),
     INDEX idx_is_revoked (is_revoked)
   ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

   CREATE TABLE IF NOT EXISTS share_files (
     id INT AUTO_INCREMENT PRIMARY KEY,
     session_id INT NOT NULL,
     original_name VARCHAR(255) NOT NULL,
     stored_name VARCHAR(255) NOT NULL,
     file_path VARCHAR(500) NOT NULL,
     file_size BIGINT NOT NULL,
     mime_type VARCHAR(127) NOT NULL DEFAULT 'application/octet-stream',
     storage_driver VARCHAR(32) NOT NULL DEFAULT 'local',
     created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
     INDEX idx_session_id (session_id),
     CONSTRAINT fk_session_files FOREIGN KEY (session_id) 
       REFERENCES share_sessions (id) ON DELETE CASCADE
   ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

2. Create Automated Migration Runner:
   File: backend/database/migrate.js
   -----------------------------------------------------------------------------
   import fs from 'fs';
   import path from 'path';
   import { fileURLToPath } from 'url';
   import mysql from 'mysql2/promise';
   import dotenv from 'dotenv';

   dotenv.config();

   const __filename = fileURLToPath(import.meta.url);
   const __dirname = path.dirname(__filename);

   async function runMigration() {
     const isUrlConfig = Boolean(process.env.DATABASE_URL);
     let connection;

     try {
       if (isUrlConfig) {
         connection = await mysql.createConnection({
           uri: process.env.DATABASE_URL,
           multipleStatements: true,
           ssl: process.env.DATABASE_URL.includes('ssl=') ? undefined : { rejectUnauthorized: false }
         });
         console.log('Connected using DATABASE_URL.');
       } else {
         connection = await mysql.createConnection({
           host: process.env.DB_HOST || '127.0.0.1',
           port: Number(process.env.DB_PORT) || 3306,
           user: process.env.DB_USER || 'root',
           password: process.env.DB_PASSWORD || '',
           multipleStatements: true
         });
         console.log(`Connected to MySQL server at ${process.env.DB_HOST || '127.0.0.1'}:${process.env.DB_PORT || 3306}`);
       }

       const schemaPath = path.join(__dirname, 'schema.sql');
       const sql = fs.readFileSync(schemaPath, 'utf8');

       console.log('Executing database migrations...');
       await connection.query(sql);
       console.log('Migration completed successfully.');

       await connection.end();
       process.exit(0);
     } catch (err) {
       console.error('Migration failed:', err);
       if (connection) await connection.end();
       process.exit(1);
     }
   }

   runMigration();

3. Database Pool (backend/src/config/db.js):
   - Uses mysql2/promise with connection pooling.
   - Automatically supports DATABASE_URL (for Cloud TiDB) and individual params.
   - Enables SSL for cloud hosted MySQL automatically.

4. File Security Utility (backend/src/utils/fileSecurity.js):
   - generateShareToken(): crypto.randomBytes(16).toString('hex') -> 32 hex chars.
   - generateRevokeToken(): crypto.randomBytes(24).toString('hex') -> 48 hex chars.
   - sanitizeFilename(): Strips null bytes, path traversal "../", invalid control chars.
   - generateStoredFilename(): Unique random hash with safe extension.

5. Storage Service (backend/src/services/storageService.js):
   - Seamless pluggable storage:
     * When STORAGE_DRIVER='local': Uses disk storage in ./uploads with resolveSafePath traversal protection.
     * When STORAGE_DRIVER='s3': Connects to Supabase / Cloudflare R2 / AWS S3 using @aws-sdk/client-s3 with PutObject, GetObject, DeleteObject commands.

6. Auto Cleanup Service (backend/src/services/cleanupService.js):
   - Runs every 15 minutes via node-cron (and on server boot).
   - Queries sessions where expires_at < NOW() or is_revoked = 1.
   - Deletes files physically from disk or S3 bucket.
   - Deletes database session records with cascading foreign key deletion.

7. Middleware:
   - Rate Limiter (backend/src/middleware/rateLimiter.js):
     * apiLimiter: 300 req/15min.
     * uploadLimiter: 30 uploads/15min per IP.
     * downloadLimiter: 120 downloads/15min per IP.
   - Upload (backend/src/middleware/upload.js):
     * Multer disk storage, 50MB per file, max 10 files.
     * Blocks dangerous executables (.exe, .bat, .cmd, .sh, .vbs, .php, etc.).
   - Error Handler (backend/src/middleware/errorHandler.js):
     * Handles Multer errors (LIMIT_FILE_SIZE, LIMIT_FILE_COUNT), path traversal, and generic errors.

8. Controller (backend/src/controllers/shareController.js):
   - createShareSession: Validates files, generates tokens, inserts session and file records in a transaction, persists to S3 if configured.
   - getShareSession: Retrieves public metadata, checks expiry and revocation, hides internal stored names.
   - downloadSingleFile: Streams file with Content-Disposition: attachment, Content-Type, and nosniff headers.
   - downloadAllFiles: Dynamically creates and streams a compressed .zip archive using archiver directly to HTTP response.
   - revokeShareSession: Validates revokeToken against database, deletes physical files immediately, marks is_revoked = 1.

9. Routes (backend/src/routes/shareRoutes.js):
   - GET  /api/health
   - POST /api/upload
   - GET  /api/session/:token
   - GET  /api/download/:token/:fileId
   - GET  /api/download-all/:token
   - POST /api/revoke

10. Express App & Server (backend/src/app.js & backend/src/server.js):
    - Configures Helmet headers, CORS allowing localhost, LAN, *.vercel.app, *.onrender.com.
    - Listens on 0.0.0.0 (all network interfaces).

16. SECURITY & MAINTENANCE REFERENCE MANUAL
================================================================================
1. Cryptographic Entropy:
   - Public download tokens: 32 hex chars (2^128 combinations). Impossible to guess.
   - Owner revocation keys : 48 hex chars (2^192 combinations). Secret to uploader.

2. Path Traversal & Injection Prevention:
   - All uploaded filenames are stripped with path.basename() and sanitized of null bytes.
   - Stored filenames use random hashes.
   - Path resolution checks resolveSafePath boundary before disk access.
   - SQL queries use 100% parameterized statements with ? placeholders.

3. Content-Disposition:
   - Served strictly with:
     * Content-Disposition: attachment; filename="..."
